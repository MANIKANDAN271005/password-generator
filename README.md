# 🔐 Secure Password Generator

A modern and responsive password generator built using **HTML, CSS, and JavaScript**. It helps users create strong, secure passwords with customizable options and provides a clean glassmorphism user interface.

## ✨ Features

- 🔐 Generate secure random passwords
- 📏 Adjustable password length (4–32 characters)
- 🔠 Uppercase letters
- 🔡 Lowercase letters
- 🔢 Numbers
- 🔣 Special symbols
- 💪 Password strength indicator
- 📋 One-click copy to clipboard
- 👁️ Show / Hide password
- 🌙 Dark Mode
- 🕒 Password history
- 🗑️ Clear password history
- 💾 Local Storage support
- 📱 Fully responsive design
